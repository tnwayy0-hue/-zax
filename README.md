# الرفع على Railway (5 خطوات)

1. ارفع محتوى هذا المجلد إلى GitHub (مستودع جديد).
2. railway.app > New Project > Deploy from GitHub repo.
3. أضف Volume بمسار: /data
4. Variables: CHANNEL_INVITE_CODE = كود قناتك
5. افتح Logs وامسح QR من واتساب > الأجهزة المرتبطة.

لتعديل الرسائل: عدّل messages.json.
